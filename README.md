CUSTOMER SHOPPING BEHAVIOUR ANALYSIS
====================================

Project Overview

This project analyzes customer shopping behaviour using Python to identify purchasing patterns, customer preferences, and spending trends. It involves data cleaning, exploratory data analysis (EDA), and data visualization to generate meaningful business insights. A detailed project report is also included, documenting the analysis and findings.

Project Objectives

• Analyze customer purchasing patterns and preferences.
• Explore spending trends across customer demographics and product categories.
• Examine the relationship between discounts, subscriptions, and shipping methods and customer shopping behaviour.
• Identify insights that support data-driven business decisions.

Dataset Description

The dataset contains customer shopping information, including:

• Customer demographics: Age and Gender
• Purchase details: Item Purchased, Category, and Purchase Amount
• Shopping preferences: Size, Color, and Season
• Customer feedback: Review Rating
• Purchase behaviour: Previous Purchases and Frequency of Purchases
• Shopping services: Subscription Status, Shipping Type, Discount Applied, and Payment Method

Tools & Libraries

• Python — Programming and data analysis
• Pandas — Data cleaning and manipulation
• NumPy — Numerical operations and data processing
• Matplotlib — Data visualization
• Seaborn — Statistical data visualization
• Google Colab — Development environment

Project Workflow

• Data loading and inspection
• Data cleaning and preprocessing
• Exploratory Data Analysis (EDA)
• Data visualization
• Interpretation of findings and business insights

Key Outcomes

The analysis explores customer purchasing behaviour, product preferences, spending patterns, and shopping trends to support a better understanding of customer needs and business performance.
